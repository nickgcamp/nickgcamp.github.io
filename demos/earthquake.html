About this demo

  • Data is illustrative: the homes are 1,000 sample points clustered around California cities.
  • The red and yellow cutoffs are illustrative. Move the sliders to set your own.
  • The original tool cleaned real addresses with the USPS address API and geocoded them with Google Maps. This demo skips those calls and starts from sample coordinates.
  • "Fast-moving" means a fault that slips at least 5 mm a year in the fault model, such as the San Andreas. Distance is straight-line miles to the nearest mapped fault trace.
  • Fault traces: GEM Global Active Faults Database (Styron and Pagani, 2020, Earthquake Spectra). Its California traces come from the UCERF3 fault model (Dawson and Weldon, 2013), built by the USGS, the California Geological Survey and SCEC. Shared under CC BY-SA 4.0, and the fault data on this page is shared the same way.
  • State outlines: U.S. Census Bureau cartographic boundaries, via us-atlas.
  • This is a demo for showing a method. It is not a hazard assessment.
